# Baklib Feedback（客户反馈）模板

[English](README.md) | 简体中文

这是客户反馈和公开路线图：一条反馈是一个页面（Page），回复挂在这页上。适合收集建议、问题和投票，并展示路线图。不适合知识库，也不适合企业官网。

内容模型在 `docs/`。构建见英文 [README.md](README.md) 的 Build 一节。
